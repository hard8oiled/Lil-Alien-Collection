# Little Aliens!
This is just a small collection of class assignments experimenting with p5.js using alien imagery.
### Alien Migration
A simple sketch using arrays to produce a consistent flow of random aliens on screen, one alien controlable via cursor.
### Alien Simulator
Experiment with image importing, just a fun and interactive screen to mess with for 20 seconds.
### Alien Ambush
Testing for loops. Static image of an alien coming for your face.
### Alien Breakdance
Experiment with extended libraries. Using p5.Tween to ad a small bit of animation to the otherwise static alien shape.
